# Task Manager

Jednoduchá konzolová aplikace pro správu úkolů vytvořená v Pythonu.

## Funkce

Aplikace umožňuje:

* přidat nový úkol,
* zobrazit seznam úkolů,
* odstranit úkol,
* ukončit program.

Každý úkol obsahuje název a popis.

## Požadavky

* Python 3.10 nebo novější

## Spuštění projektu

Projekt spustíte pomocí příkazu:

```bash
python task_manager.py
```

Po spuštění se zobrazí hlavní menu, ve kterém lze vybrat požadovanou akci.

## Testovací případy

Testovací případy jsou uvedeny v souboru `test_cases.md`.

Testy pokrývají jednotlivé funkce aplikace a obsahují očekávaný i skutečný výsledek testování.
